# Capítulo 3: Asignación de probabilidades

## 1. Regla de Laplace

Si en un espacio muestral $\Omega = \{\omega_i\}_{i=1}^n$ cada $P(\{\omega_i\}) = p$ es igual para cada evento simple (es decir, el espacio es equiprobable), entonces la probabilidad de un suceso $A$ es:
$$ P(A) = \frac{\text{nº de casos favorables en } A}{\text{nº de casos posibles en } \Omega} = \frac{|A|}{|\Omega|} $$

> [!warning] Cuidado
> Solo es aplicable para espacios de probabilidad equiprobables. Existen formas de "reestructurar" problemas de probabilidades para que el espacio de probabilidad sea equiprobable.

**Métodos combinatorios:**
Cuando se cumplen las condiciones de la regla de Laplace, será de especial utilidad usar técnicas de recuento (combinatoria).
